# Fraud Detection Analysis System

## Overview
This project is a Real-Time Fraud Detection System built using Python, Machine Learning, SQL, SQLite, and Streamlit. The system detects suspicious financial transactions and provides instant fraud analysis through a web-based interface.

The project includes:
- Fraud Detection using anomaly logic
- Real-Time Transaction Checking
- Transaction History Tracking
- Database Storage
- Dynamic CSV Upload
- Data Visualization

---

## Features

- Real-Time Fraud Detection
- Streamlit Web Application
- Transaction History Table
- SQLite Database Integration
- Dynamic CSV File Upload
- Fraud vs Normal Transaction Analysis
- Machine Learning Model (Isolation Forest)
- SQL Query Analysis
- Data Visualization using Matplotlib & Seaborn
